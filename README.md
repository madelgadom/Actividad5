# Actividad 5 - Machine Learning con MLflow

## Descripción
Este proyecto tiene como objetivo preparar datos, entrenar y evaluar un modelo de Machine Learning, y registrar los experimentos utilizando MLflow.

## Estructura del proyecto
- `datos/datos_ini/`: datos originales.
- `datos/datos_limp/`: datos procesados y limpios.
- `fuentes/entrena.ipynb`: notebook de entrenamiento y evaluación en Google Colab.
- `fuentes/datos_prep.py`: funciones para limpieza y preparación de datos.
- `fuentes/train.py`: script de entrenamiento y registro en MLflow.
- `README.md`: documentación del proyecto.
- `CHANGELOG.md`: registro de cambios y reporte final.

## Herramientas
- Python
- Google Colab
- GitHub
- MLflow
- Pandas y Scikit-learn

## Reproducción del proyecto
1. Descargar o clonar el repositorio.
2. Incorporar los datos originales en `datos/datos_ini/`.
3. Ejecutar el proceso de limpieza para generar los datos en `datos/datos_limp/`.
4. Ejecutar el entrenamiento y la evaluación del modelo.
5. Registrar y consultar los experimentos en MLflow.

## Decisiones técnicas
Las decisiones de limpieza, selección del modelo, métricas e hiperparámetros se documentarán conforme avance el proyecto.
